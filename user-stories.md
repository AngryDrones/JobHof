# User Stories - INVEST Kriteria evaluated 

## Final User Stories

## Student
### US-01: Register
 As a job-seeking student, I want to register an account with my email and a password, so that I can see job vacancies relevant to me.
Registration requires a valid email and a password that meets the stated rules.
An email address can only be registered once.
After registering, I can see the job listings.
### US-02: Log in
 As a registered student, I want to log in with my email and password, so that I can securely access my account.
Valid credentials give me access to my account.
Invalid credentials show a generic error that doesn't reveal which field was wrong.
### US-03: Edit profile
 As a registered student, I want to edit my personal details (name, email, address, education level, and optionally age) on my profile page, so that my account information stays up to date.
Each field can be changed and saved.
Invalid input (e.g. a malformed email) is rejected with a clear message.
Saved changes show immediately on my profile.
### US-04: Add skills, experience and CV
 As a registered student, I want to add my skills and work experience and upload my CV to my profile, so that recruiters can evaluate my suitability.
I can add and remove skills and experience entries.
I can upload, replace and delete a CV (accepted formats and maximum size are defined).
The information appears on my profile.
### US-05: Apply with my profile
 As a career-oriented student, I want to apply to job postings of registered local companies using my existing profile, so that I don't have to fill in long application forms repeatedly and can react quickly between lectures.
Every open job posting has an "Apply" button.
Applying sends my profile data and CV to the company without further form entry.
I get a confirmation, and the application appears in my application list.
I cannot apply twice to the same posting.
## Recruiter
### US-06: Create a job posting
 As a company recruiter, I want to create a job posting with job title, description, required skills, employment type, location, pay range and application deadline, so that students can discover suitable opportunities and apply.
Title, description and deadline are mandatory; the other fields are optional.
The deadline cannot be in the past.
A published posting appears in the student job listings.
### US-07: Edit and close a job posting
 As a company recruiter, I want to edit or close my existing job postings, so that students only see accurate, open vacancies.
I can edit all fields of my own postings, and changes appear immediately.
Closed or expired postings disappear from the listings and no longer accept applications.
### US-08: Search and filter applicants
 As a company recruiter, I want to search and filter the applicants for a specific job posting by skills, education, experience and application status, so that I can quickly identify students who meet the requirements.
Only applicants of the selected posting are shown.
Filters can be combined, and the list updates accordingly.
### US-09: Review applicant profiles and CVs
 As a company recruiter, I want to view an applicant's profile and CV next to the job requirements, so that I can assess how well they fit the vacancy.
The profile and CV open from the applicant list.
The posting's required skills are visible alongside the applicant's data.
### US-10: Shortlist candidates
 As a company recruiter, I want to add promising applicants to a shortlist, so that I can organise the process and decide whom to invite to the next stage.
I can add and remove candidates on a shortlist per posting.
The shortlist can be viewed separately.
